# Utilidades

- `launch_app.py`: arranque normal desde el entorno local, servidor en segundo plano y Chrome.
- `maintenance.py`: limpieza comprobable; por defecto solo genera un plan.
- `experiments/<fecha>/`: scripts de renders históricos, conservados como referencia. Ejecutar desde la raíz del proyecto; pueden generar archivos o necesitar los recursos de aquella prueba.

Guía: [estructura y arranque](../docs/ESTRUCTURA_Y_ARRANQUE.md).
